# IdeaForge — User Journeys & Core Features

---

## 3. CORE USER JOURNEYS

### Journey A: Founder — From Idea to Funded
```
Sign Up → Create Founder Profile (bio, skills, country, LinkedIn) 
→ Submit Idea (title, problem, solution, category, stage)
→ Upload assets (pitch deck PDF, demo video, prototype link)
→ Set funding goal + model (equity / revenue share / milestone)
→ Idea goes to "Validation Queue" (community testing phase, 14 days)
→ Receive structured feedback, ratings, and expert reviews
→ Idea promoted to "Investor Discovery Feed" based on Validation Score
→ Investors bookmark / message / commit funds
→ Milestone tracking begins post-funding
→ Founder updates investors with progress updates
```

### Journey B: Tester / Validator — Discover & Review
```
Sign Up → Browse "Needs Validation" feed (filter by category/stage)
→ Select an idea → Read pitch, watch demo video, test prototype link
→ Complete structured review form (problem clarity, solution fit, market size, founder credibility)
→ Submit rating (1–10 across 5 dimensions)
→ Earn Validator Points → Unlock Expert Validator badge after 50 reviews
→ Get notified when validated ideas raise money (social proof)
```

### Journey C: Investor — Discover to Fund
```
Sign Up → Complete investor profile (type, ticket size, sectors, geography)
→ KYC/accreditation verification (for equity rounds)
→ Browse "Investor Discovery Feed" (ideas sorted by Validation Score, traction, stage)
→ Filter by: sector | stage | country | funding model | ticket size
→ View Idea Page: full pitch, financials, founder profile, validation score, community reviews
→ Add to Watchlist OR message founder
→ Commit investment (escrow holds funds)
→ Track portfolio: milestone updates, progress posts, returns dashboard
```

### Journey D: Accelerator — Source & Recruit
```
Create Institution Profile → Browse "Batch Sourcing" mode
→ Filter ideas by stage (pre-product, MVP, post-revenue)
→ Invite founders to apply to programs directly from platform
→ Run virtual "Demo Day" events on platform
→ Post cohort announcements to attract more founders
```

## 4. CORE PLATFORM FEATURES

### 4.1 Registration & Profiles
| Feature | Details |
|---|---|
| Multi-role signup | Founder, Investor, Tester, Mentor, Accelerator |
| Social login | Google, LinkedIn, GitHub |
| Profile completeness score | % bar nudging users to complete profiles |
| Founder profile | Bio, skills, country, past startups, social links, ideas posted |
| Investor profile | Type (angel/VC/passive), sectors, geography, portfolio, ticket size |
| Mentor profile | Expertise, hourly rate, availability, past mentees |
| Identity verification | Email → Phone → KYC (for investors committing funds) |

### 4.2 Idea Submission
| Feature | Details |
|---|---|
| Idea submission wizard | 6-step guided form |
| Step 1 | Title, tagline, category (B2B/B2C/DeepTech/etc.), stage |
| Step 2 | Problem statement (500 words max, guided prompts) |
| Step 3 | Solution description + key differentiators |
| Step 4 | Target market, TAM/SAM/SOM estimates |
| Step 5 | Upload: pitch deck (PDF/PPT), demo video (mp4/YouTube), prototype URL |
| Step 6 | Funding details: goal, model, equity offered, milestones |
| Draft saving | Auto-save at each step |
| AI Assist | GPT-powered assistant to help write problem/solution sections |

### 4.3 Validation System
| Feature | Details |
|---|---|
| Validation Queue | New ideas enter 14-day community validation phase |
| Structured review form | 5-dimension scoring: Problem Clarity, Solution Uniqueness, Market Potential, Founder Credibility, Demo Quality |
| Validation Score (VS) | Weighted composite score 0–100 |
| Expert Review | Paid mentors can submit "Expert Review" reports |
| Tester Reports | Beta testers submit UX reports on prototypes |
| Validation badge tiers | "Community Validated" (>60 VS), "Expert Verified" (mentor review), "Market Tested" (user testing done) |

### 4.4 Discovery & Search
| Feature | Details |
|---|---|
| Explore Feed | Card-based idea feed with VS score, funding progress bar, category |
| Smart Filters | Stage, sector, country, funding model, ticket size, validation score |
| Trending | Based on views, bookmarks, new reviews in 48hrs |
| Search | Full-text search on idea title, tags, founder name |
| Recommended | Personalized based on investor profile preferences |
| Collections | Curated lists: "Hot in AI", "African Founders", "Under $10K" |

### 4.5 Idea Detail Page
| Feature | Details |
|---|---|
| Hero section | Title, tagline, category badge, validation score, funding progress bar |
| Pitch deck viewer | Embedded PDF viewer (no download by default) |
| Demo video | Inline video player |
| Prototype link | External link with "Report Issue" option |
| Founder card | Photo, bio, past ideas, response rate |
| Community reviews tab | All tester/validator reviews with ratings |
| Expert review tab | Mentor reports (premium) |
| Q&A section | Public Q&A between community and founder |
| Investment section | Funding model, equity %, goal, deadline, current raised, investors |
| Milestone tracker | Publicly visible milestone roadmap |

### 4.6 Investment & Funding
| Feature | Details |
|---|---|
| Investment commitment | Investor commits amount → escrow holds |
| Milestone-release | Funds released to founder upon milestone completion + verification |
| Portfolio dashboard | All investments, status, returns, updates |
| Deal room | Private document sharing for due diligence |
| Term sheet generator | Standardized template for simple agreements |
| Transaction history | Full audit trail for compliance |

### 4.7 Communication
| Feature | Details |
|---|---|
| Founder ↔ Investor messaging | Post-commitment DM unlocked |
| Public Q&A | On idea page, publicly visible |
| Notification center | Email + in-app + push (mobile) |
| Mentor booking | Schedule 30/60-min sessions, pay via platform |
| Investor syndicates | Group chat for co-investors on same deal |

### 4.8 Admin & Moderation
| Feature | Details |
|---|---|
| Content moderation | AI + human review of new idea submissions |
| Fraud detection | Duplicate idea check, identity mismatch alerts |
| Idea flagging | Users flag suspicious content |
| KYC queue | Admin review of investor KYC submissions |
| Platform analytics | MAU, idea submissions, funding volume, review velocity |
| Fee management | Set platform fee %, manage payouts |
